# Better ManageBac public roadmap

Public page: https://abiel990310.github.io/better-managebac-roadmap/

Suggestions: https://github.com/Abiel990310/better-managebac-roadmap/issues

This repository contains only the public website and owner-approved product information. No extension source, student information or school screenshots belong here.

## Reviewing ideas

1. Read the issue and check usefulness, duplicates, accessibility and compatibility across schools.
2. Present a concrete proposal and acceptance criteria to the owner. Ask for approval in the owner's chat.
3. Only after explicit owner approval, add the idea to `data.js` with an honest stage and no promised date unless agreed. Close or comment on the issue only when the owner authorizes messaging that visitor.
4. Update `updated`, preview light/dark and mobile, and publish the static files. Store uploads are not confirmed public releases.

Issue labels or votes never publish ideas automatically. A release still requires testing and approval of the exact build. The owner can subscribe to repository issue notifications on GitHub.

The extension project's `public-roadmap/` folder is the editing source; sync approved website changes here.
